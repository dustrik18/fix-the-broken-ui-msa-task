# Standup Tracker (Starter)

A small React app for tracking a team's daily standup status. It has four bugs planted in it on purpose:

- a stale closure that shows the wrong value
- a missing list key causing weird re-render behavior
- a layout bug that only appears on narrow screens
- an accessibility issue a screen reader would catch

Find all four, fix them, and add a one-line comment at each fix explaining what was actually wrong.

This is a debugging task, not a rebuild — please don't rewrite the app from scratch.

## Running locally

```
npm install
npm run dev
```

Requires Node 18 or newer.
